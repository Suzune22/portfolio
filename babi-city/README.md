# Babi City

Prototype de jeu en monde ouvert inspiré de GTA V, à Abidjan : Adjamé, le Plateau et Cocody.
Il tourne dans le navigateur, sans installation : ouvrir `index.html` via un serveur web
(par exemple GitHub Pages, ou `python3 -m http.server` à la racine du dépôt).

Le document de conception complet est dans [GDD.md](GDD.md).

## Commandes

| Action | Clavier / souris |
|---|---|
| Se déplacer, conduire | ZQSD (AZERTY), WASD (QWERTY) ou flèches |
| Caméra | Souris (cliquer dans le jeu pour la capturer) |
| Courir | Maj |
| Sauter, frein à main | Espace |
| Monter, descendre, braquer un véhicule | F |
| Viser, tirer | Clic droit, clic gauche |
| Changer d'arme | X |
| Changer de personnage | 1 (Koffi), 2 (Bakary), 3 (Séry), Tab pour la roue |
| Radio, klaxon, course de taxi | R, H, J |
| Carte, pause | M, Échap |

Sur téléphone ou tablette, des commandes tactiles s'affichent (joystick et boutons).

## Mentions

Projet non officiel, sans lien avec Rockstar Games. Personnages, marques et
événements sont fictifs. Three.js est chargé depuis jsDelivr ; tout le reste
(textures, musique, sons) est généré par le code.
